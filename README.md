# OAN Public Docs

Public documentation and specification material for OpenAgenet (OAN), an open
infrastructure project for the Internet of Agents (IoA). This repository hosts
reader-facing documentation for DID-based resource identity, `did:oan`,
registration, semantic discovery, trust-aware discovery, verification, and
public research material.

## Start Here

- [Architecture overview](docs/design.md)
- [Official homepage public guide](docs/official-homepage-public-guide.md)
- [Resource registration and discovery guide](docs/resource-registration-and-discovery-guide.md)
- [did:oan method specification](did-oan-specs/doc/OAN%20DID%20Method%20Specification.md)
- [Error codes](docs/error-codes.md)
- [White paper](papers/OAN-White-Paper.pdf)
- [Yellow paper](papers/OAN-Yellow-Paper.pdf)
- [Chinese and English slides](docs/slides/)

The official public website is <https://www.openagenet.xyz>. Its Docs page
publishes the user-facing version of the same documentation set.
