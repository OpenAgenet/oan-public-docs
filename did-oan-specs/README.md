# did-oan

The current OAN implementation target is
[`OAN DID Method Specification v2.md`](doc/OAN%20DID%20Method%20Specification%20v2.md).

The original [`OAN DID Method Specification.md`](doc/OAN%20DID%20Method%20Specification.md)
is retained only as the legacy profile-v1 migration baseline. New SDKs,
Registrars, Root services, fixtures, and production deployments MUST NOT use
its four-character `semantic-code` syntax as the active profile.
